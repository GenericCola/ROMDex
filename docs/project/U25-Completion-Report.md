# U25 — Validated Independent/Grouped Result Application

**Completed in source:** October 19, 2026. Installed ROMDex remains **0.5.15**. No installer, production migration or live-save change was performed.

## Result

ROMDex can apply a safe authorized agent return to NPCD and the managed map RDX, preserve newer drafts and unrelated data, and recover an interrupted application without applying it twice. Independent results can complete separately; dependent changes apply as a complete group. Accepted changes require human review/testing and leave the actionable task open.

Auto-Sync processes eligible returns. Manual Save performs one bounded cycle with Auto-Sync Off. The existing Check for Returned Files action remains read-only. Package progress distinguishes Applied / Needs Human Testing, accepted work awaiting sync, and held results. No additional menu or editing redesign was introduced.

Acceptance requires fresh native provenance, exact pinned file bytes, current conflict-free authorization, concrete authorized patches, valid stable IDs/mappings, unchanged read baselines and complete outcomes. A private metadata acknowledgment precedes content writes, preventing task-file approval claims from authorizing native implementations on another computer. Concurrent authorization withdrawal and acceptance enter review. Accepted work has a durable journal, immutable evidence, preserved raw return bytes and testing obligations across private-metadata/native/managed-store boundaries.
