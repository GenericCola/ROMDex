# U21 Package Contract Clarification

The RD09 ZIP and RD01 reference folder are frozen historical contract/tooling snapshots. Current authoritative package schemas and tools are in the [application source](../../apps/romdex/rdx/authoring/README.md), with the [U21 package guide](../../apps/romdex/rdx/MAP-PACKAGES.md).

The user approved context-only JSON Map Packages. `NPCDexMapPackage/2.requests` may therefore be empty; FINAL decisions, flags and notes never authorize ROM changes. There is no extra user-facing Draft/Ready step. Selected CHANGE/REMOVE/ADD entries define requested scope after explicit preview confirmation and separate human handoff. Original artifact metadata stays intact as provenance.

Required assets—including current NPCDex display images—are attached and byte-verified on the chosen YouTrack task before the fixed JSON and exact task binding are attached. The JSON identifies current image associations as context. Complete working RDX files and unchecked plans/notes/history remain local. Do not reinterpret omissions as deletion instructions or require the agent to access private GitHub saves.

U21 is implemented and verified in source; installed 0.5.15 does not gain these menus until a later packaged release. U23–U27 still own task-bound returned-RDX automation and human-testing gates. Existing map/plan RDX formats and the original native artifact schemas are unchanged.
