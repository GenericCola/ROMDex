# MAPDex 0.5.21 — Parent/Child Map Groups and Contextual Preview

Status: complete; installed and reopened with the current preparation and remembered connections.

Select a map in Tray 1. Its standard Settings button offers Assign to Parent. Choose the parent (or no parent), review the nested output, then apply and Prepare Map. Sprout Tower becomes a child zone of Violet City; its three floors and their entities remain beneath it. Violet City exports one map RDX. Child groups remain navigable in the indented catalog rather than remaining standalone map files.

This extends the app’s existing building/floor/entity organization to user-selected logical groups. It does not imply that floors were a newly introduced concept. Physical records and portable contracts now preserve arbitrarily nested subzones up to the catalog’s reviewed eight-level safety bound.

Unpublished parent preparations can extend to include new source areas while retaining their identities, custom display names, images, source text, notes, plans, timeline evidence and history. Independently prepared child RDX datasets and maps already handed to NPCDex are identified and blocked for a separate migration review; this build does not silently combine their distinct histories.

Linked source dialogue is expanded by default under readable prompt headings. All gender alternatives and source text are retained. Stage filters have a Show All Source Dialogue recovery. Technical conditions and IDs remain optional evidence. Missing links are reported rather than guessed. The top-right pane-size button is removed; TAB cycles Default/Expanded/Collapsed from workspace content, leaving ordinary input/menu navigation intact.

The supplied ROM proof uses one Violet City map, Sprout Tower as a child container, eleven real source areas, three tower floors and 93 entities. It preserves the previous source identities and a deliberately reviewed display name. It does not edit the user’s prepared New Bark Town or publish a production map. A small fictional nested dataset will separately verify the live YouTrack hierarchy and be removed afterward.

Location-preview implementation is separately scoped in the [location preview plan](MAPDex-Location-Preview-Scope.md). No terrain rendering is included in 0.5.21. Universal Pokémon ROM compatibility, live independent-map migration and NPCD Epic/Saga/Story/Verse Type labels remain open; the actual parent/child links are a separate concern.
