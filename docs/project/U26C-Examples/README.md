# U26C fictional one-map examples

These are synthetic test data, not extracted ROM content. Each file contains exactly one map and its dependencies. The final file includes an NPCDex note, a later local note and an independently edited YouTrack title accepted through review. Images, attachment bytes, plans and history are preserved. Human testing remains Unreviewed.

- Original-Test-Map.rdx: clean input before local editing or cloud publication.
- Verified-Round-Trip-Map.rdx: portable output after the completed local/YouTrack round trip.

Use an isolated profile for inspection. Importing creates a local working document and does not automatically publish or replace current maps. The export contains no saved credential or private cloud-binding authority. This exercise does not authorize resetting production content or resuming the paused production queue.
