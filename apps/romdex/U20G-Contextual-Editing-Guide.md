# Contextual Editing and Review

Select a character or item, choose its dialogue entry and passage, then use Flags & Notes, Plan Changes or CHANGE / FINAL / REMOVE in Tray 3. The form identifies the exact location and current dialogue. Target selectors are hidden from ordinary editing; history and workflow choices are under History & Advanced Options.

The form body scrolls independently of its action footer. Closing retains a touched draft. Drafts for other targets are preserved instead of forcing an unrelated draft over the selected entry; use More Actions → Review Sync to resume them. Discard Editor Draft affects only the current context. Existing drafts keep their original baseline, including trailing whitespace and saved images.

Flags, Notes & Changes in Tray 1 groups readable entries into Changes, Notes and Finalized. Each shows its map/sub-zone, target, condition, current dialogue and actual proposal/note. Finalized starts collapsed. Click the target to navigate, or Edit Changes / Edit Note to edit its existing version. Conflicting heads require explicit review. A saved request spanning multiple passages retains its original scope; its instructions/notes can be edited without silently rewriting one passage as the entire request.

Add Character is beside Male/Female in Tray 2. It uses the selected sub-zone when unique; otherwise choose a destination within the current map. A new character remains a Planned Addition. Planning never dispatches an agent or marks ROM implementation complete.

Content storage, original records/history, synchronization controls, conflict protection and remembered connections are preserved. Existing image/edit/cache limits still apply. U21 map-package functionality is a separate task.
