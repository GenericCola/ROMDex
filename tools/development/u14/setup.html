Cloud Storage Access

Private Save Repository: GenericCola/ROMDex-Data

Your existing YouTrack connection and read-only update token stay unchanged. This separate token lets ROMDex publish private saves when cloud synchronization is implemented.

  1. Open GitHub Token Settings and choose GenericCola as Resource Owner.
  2. Choose Only Select Repositories → ROMDex-Data.
  3. Set Repository Permissions → Contents → Read and Write. Leave other optional permissions off.
  4. Generate the token and paste its value below.

No NPCDex saves will be uploaded during setup.

The token is protected by Windows and retained in ROMDex’s application Data folder. Setup tests private access with an empty temporary branch; your saves remain local until the later migration review.
