# RI03U development evidence helpers

Historical task scripts, retained for reproduction and review. Their original working root was work/ri03u; they are not application commands. The real-ROM checks require the user-supplied read-only ROM, which is excluded, and the live helper requires a normal Windows launch to unlock existing protected credentials. Generated profiles, ROM-derived RDXs, Data, credentials, binaries and signed/private keys are excluded. Run only against explicitly isolated fixtures and ownership-marked private test records. No automatic repository job executes these files.
