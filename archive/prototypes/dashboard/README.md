# ProjectDex prototype

Double-click `index.html` to open the prototype in your browser. No installation, account, or coding is required.

Try the project buttons, List / Board switch, search, and “Plan the first version” button. All tasks are fictional examples. Nothing connects to or changes YouTrack yet.

The theme reuses the actual NPCDex palette, red shell, green panels, cream text, yellow highlights, and blue lens from the existing project.

## Files

- `index.html`: page structure.
- `styles.css`: NPCDex theme and responsive layout.
- `app.js`: sample tasks and interactive views.
- `SCOPE.md`: decisions to settle before feature development and live integration.

This is a local, plain HTML/CSS/JS foundation. It has no frameworks or external dependencies.
