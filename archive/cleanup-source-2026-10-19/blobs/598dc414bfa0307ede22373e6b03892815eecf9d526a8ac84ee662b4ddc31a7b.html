Shared scenes use one record; flags and notes are the same from every participant’s pane. Save changes includes all annotations in the agent export.

Content & saving

Save changes commits the current content, flags, notes, tester statuses, images, and player preference to this browser, then downloads a complete JSON export for agent use. Exported files are snapshots; use Import to restore or preview an updated dataset.

Uploaded and downloaded images are embedded data URLs. The interface makes no image-host requests when displaying saved images. Edits remain pending until Save changes succeeds. Moving dialogue pages retains pending notes.

Timing and character identities follow the supplied research. Conditions and alternative branches are documented, rather than simulated as ROM flags. Shared prompts and apparently unused text remain separate reference locations.
