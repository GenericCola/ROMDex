Content & Saving
Save changes commits the current content, flags, notes, tester statuses, images, and player preference to this browser, then writes a complete JSON export to your chosen package folder, overwriting the previous export. Choose the folder containing this HTML on the first save. The same npcdex-agent-export.json file is replaced on later saves; use Import to restore or preview an updated dataset.
Select a dedicated NPCDex folder, not Downloads itself. Extract the ZIP into a folder such as Downloads / NPCDex, then select that folder containing npcdex.html. If the browser says the folder contains system files, enter or create a subfolder in the picker and select it. Your edits remain pending until saving succeeds.
Uploaded and downloaded images are embedded data URLs. The interface makes no image-host requests when displaying saved images. Edits remain pending until Save changes succeeds. Moving dialogue pages retains pending notes.
