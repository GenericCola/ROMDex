Adding to the atlas

The interface reads a versioned JSON content model. Add a town to towns, nest rooms in its areas, then add NPCs or elements with their dialogue points. Export the current data as a starting point; import your edited file to preview it. An import replaces the current dataset after validation.

{ "id": "new-area", "name": "New room", "code": "map code",
  "elements": [{ "id": "npc", "name": "NPC name", "events": [],
    "context": "Availability and branch notes",
    "points": [{ "id": "npc-first", "condition": "Trigger event",
      "stages": ["B"], "ids": [], "uncertain": false,
      "blocks": [{ "type": "dialogue", "text": "Exact words" }],
      "evidence": [] }] }] }

Use ["all"] for dialogue documented throughout the story. Use [] when timing is unknown or depends on a separate condition. Choices and repeat visits are documented inside sequences; they do not automatically advance the story. Keep inferred timings and identities marked uncertain.

Imports are stored locally in this browser when storage is available. The portable HTML includes the original dataset. Export edited data to keep a portable copy.
