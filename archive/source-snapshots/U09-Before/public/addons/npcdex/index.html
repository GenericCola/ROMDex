Content & Saving
Save changes commits the current content, flags, notes, tester statuses, images, and player preference to this browser, then writes a complete JSON export to your chosen package folder, overwriting the previous export. Choose a dedicated NPCDex save folder on the first save. The same npcdex-agent-export.json file is replaced on later saves; use Import to restore or preview an updated dataset.
Select a dedicated NPCDex save folder. You can select your existing extracted NPCDex package folder. Save Changes writes npcdex-agent-export.json there; your chosen folder remains the manual save destination.
Uploaded and downloaded images are embedded data URLs. The interface makes no image-host requests when displaying saved images. Edits remain pending until Save changes succeeds. Moving dialogue pages retains pending notes.
