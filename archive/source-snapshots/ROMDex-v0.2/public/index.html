    Make the Hierarchy Yours

    Epic → Story → Verse
    Epics contain Stories; Stories contain Verses; deeper levels are Tasks. Select a Verse to see only its dependent tasks. These labels do not rename YouTrack Type values.
    Drag the Grip
    Move above or below a row. Drag right to nest; drag left to move up a level. Drop onto a selector to move into it.
    Hover a Row → +
    Add a child and start typing its name.
    Enter
    Save the name and start the next row. On an empty new row, remove the draft.
    Tab / Shift+Tab While Naming
    Nest under the previous item / move out one level.
    Escape
    Cancel the current title editor.
    Double-Click a Title or Use ✎
    Rename it inline.
    Status Lights
    Grey untouched; yellow in progress; red critical/debugging; green complete; blue standby. Parent lights summarize their descendants automatically.
