# ROMDex 0.4.0 — October 14, 2026

This release completes the approved R01–R08 enhancement plan before unified NPCDex/ROMDex desktop development.

- Epic → Saga → Story → Verse selectors use compact 48 px text tiles, exclusive expansion and the existing cog. Saved images remain available in Tile Settings. Deeper tasks stay in Work.
- Work adds fixed drag/checkbox gutters, Shift/Ctrl selection, named sibling grouping, and bulk moves that preserve complete subtrees. Interrupted groups retain confirmed work and recover the remainder.
- Name clicks reopen Details. Checkboxes, notes and attachments preserve collapsed Details. TAB follows the approved name-edit/group/pane priorities; ESC clears selection before toggling the pane.
- In Development flashes purple and overrides inherited statuses except Critical/red. Status order is Untouched → In Progress → Standby → In Development → Complete → Critical.
- The hover pencil opens the full PMON editor, including assignee, due date, editable custom fields, notes and existing tags. Double-click/F2 retains quick inline rename. Calculated Spent Time stays read-only.
- Ticket attachments support durable local staging, paused/manual upload, original downloads, raster previews, incoming native changes and exact-content uncertain recovery.
- Release QA prevents late upload packets from recreating cancelled local files and standardizes Work toolbar actions at 29 px.

The saved Windows-account connection/profile and existing browser databases are retained. Original v0.2/v0.3 packages and protected baselines remain separate. See QA-Report.md and UPGRADE-AND-RECOVERY.md for verification and recovery details.

The standalone launcher, tool switcher, NPCDex cloud storage, change-request publishing and agent receipts remain separately approved future phases.
